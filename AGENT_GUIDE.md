# Moon Agent + Groq / OpenAI

Moon AI остаётся чатом с твоей моделью. Moon Agent — отдельный режим:

- **Агент с API:** модель через Groq или OpenAI выбирает наш инструмент и формирует ответ.
- **Разбор без ключа:** пошаговый сценарий, без API и расхода квоты.

## Запуск

Нужен Node.js 22.9+ или 24 LTS. Создай `.env` в корне проекта.
Если файл уже есть, добавь строки, не заменяя настройки чата:

```dotenv
AGENT_PROVIDER=groq
GROQ_API_KEY=твой_ключ_Groq
GROQ_MODEL=openai/gpt-oss-20b
```

Ключ Groq создаётся на https://console.groq.com/keys. Модель gpt-oss — от OpenAI,
но API обслуживает Groq. Бесплатный тариф имеет ограничения запросов и токенов.
Groq выбран по умолчанию и использует `https://api.groq.com/openai/v1/responses`.
Калькулятор выполняется на нашем сервере, встроенные инструменты Groq не включаются.

Для возврата к прямому API OpenAI укажи:

```dotenv
AGENT_PROVIDER=openai
OPENAI_API_KEY=твой_ключ_OpenAI
OPENAI_MODEL=идентификатор_доступной_модели
```

Этот режим использует `https://api.openai.com/v1/responses`. Ключи провайдеров
не подменяют друг друга. На хакатоне уточни доступные модели и квоту.

Ключ хранится только на сервере. Не добавляй к нему префикс `VITE_` и не вставляй
его в интерфейс или исходный код. `.env` уже исключён из Git.

В двух терминалах из корня проекта:

```bash
npm run agent:dev
```

```bash
npm run dev
```

Открой `http://127.0.0.1:1420/` → Moon Agent → Агент с API.
После изменения `.env` перезапусти сервер агента и нажми «Обновить статус».
«Настройки найдены» не означает, что доступ к модели уже проверен.
Без ключа используй «Разбор без ключа».

## Как это работает

```text
Moon AI    → существующий Python / HF backend → MoonAI
Moon Agent → Vite /api/agent → Node.js localhost:3001
                               ├─ Groq / OpenAI Responses API
                               ├─ проверка вызова calculate
                               ├─ выполнение функции
                               └─ результат обратно модели → ответ или новый вызов
```

Агент выбирает действие, получает результат и решает, что делать дальше.
Вызов функции — структурированный запрос модели; функцию исполняет наш сервер.

Попробуй: «Рассчитай стоимость 3 билетов по 1200 ₸ и добавь 10% сервисного сбора».
Модель выбирает число вызовов сама. Журнал показывает реальные вызовы,
результаты и ответ; внутренние рассуждения не выводятся.

`calculate` поддерживает add, subtract, multiply и divide. Это обычная арифметика
JavaScript с плавающей точкой, не бухгалтерская система. Нет eval, shell,
доступа к файлам или веб-поиска.

Сервер передаёт схему с `strict: true` и сам проверяет имя и аргументы.
Ошибка инструмента возвращается модели для исправления. Все элементы ответа,
включая состояние reasoning, сохраняются для продолжения текущего цикла.
В OpenAI используется `store: false`. В Groq параметры `store` и `include`
не отправляются: они пока не поддерживаются. История передаётся в каждом запросе.
Это не обещание отсутствия служебного хранения у провайдера.

## Ограничения прототипа

- До 5 запросов модели, 8 вызовов инструмента, 2048 выходных токенов на ответ и 90 секунд на запуск.
- Один активный запуск на сервер. Остановка прерывает ожидание и дальнейшие шаги; уже обработанные API-запросы могут расходовать квоту.
- Каждый запуск независим. Журнал живёт в памяти страницы и не сохраняется после перезагрузки.
- Сервер слушает только 127.0.0.1. Это локальный прототип без публичной авторизации.
- Vite-прокси работает в dev. Для сайта или собранного Tauri-приложения нужен отдельный backend, авторизация и маршрутизация `/api/agent`. Ключ нельзя упаковывать в приложение.
- Ошибки доступа и квоты показываются пользователю; подмена ответа демо-сценарием не выполняется.

## Где читать код

- `src/agent/AgentWorkspace.tsx` — переключение API / пошаговый разбор.
- `src/agent/OpenAIAgent.tsx` — задача, события и остановка.
- `server/agent.mjs` — инструмент, цикл и HTTP-транспорты Groq / OpenAI.
- `server/index.mjs` — сервер, конфигурация, таймаут и отмена.
- `server/agent.test.mjs` — проверки без ключа и платных запросов.

```bash
npm run agent:test
npm run build
```

Следующий учебный шаг: прочитай `runAgent`, затем добавь один инструмент для
конкретной задачи хакатона. Заранее сформулируй примеры успешного выполнения и
ошибок. Собственную MoonAI можно позже подключить через другой адаптер модели.

Python backend не требуется для OpenAI-агента. Ранее обнаруженные расхождения
локальных файлов 150M/700M этим изменением не исправлялись.
